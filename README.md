# Deadlock Meta Thailand (เว็บวิเคราะห์เมต้าเกม Deadlock ภาษาไทย)

เว็บแอปพลิเคชันวิเคราะห์เมต้า สถิติ และคู่มือเกม Deadlock (จาก Valve Corporation) ในรูปแบบภาษาไทยที่สมบูรณ์และอัดแน่นที่สุด พัฒนาด้วย React และระบบสถาปัตยกรรมแบบ Zero-Dependency Static Architecture

---

## ฟังก์ชันและโมดูลหลัก (Features)

1. **ภาพรวมเมต้า (Meta Overview):**
   - สรุปสถิติจากห้องแข่งระดับสูงกว่า 32.2 ล้านแมตช์ ประจำแพตช์ 2026-10-14
   - ไฮไลท์ฮีโร่ตัวท็อป: Win Rate สูงสุด, Pick Rate สูงสุด และตัวที่วินเรทพุ่งแรงสุด
   - สรุปแนวโน้มและทิศทางเมต้าเกมรายสัปดาห์
2. **ตารางจัดอันดับฮีโร่ (Hero Tier List):**
   - รวบรวมสถิติฮีโร่ครบทั้ง 39 ตัว แบ่งตามระดับ Tier (S+, S, A, B, C, D)
   - สถิติ Win Rate, Pick Rate, แมตช์ชนะ/แพ้ และ Win Rate Delta
   - ระบบฟิลเตอร์ตามระดับ Tier และสายการเล่น (Carry, Brawler, Initiator, Support, Ganker, Sniper, Mage)
   - ระบบเรียงลำดับ (Sort) ตาม Tier, Win Rate, Pick Rate และตัวอักษร
3. **สารบบและคู่มือเจาะลึกฮีโร่ (In-Depth Hero Dossier):**
   - หน้าต่างเจาะลึกรายตัวเมื่อคลิกการ์ดฮีโร่
   - รายละเอียดสกิลประจำตัวทั้ง 4 สกิลพร้อมคูลดาวน์และคำอธิบายภาษาไทย
   - ลำดับการอัปสกิลแนะนำ (Skill Priority)
   - ไอเทมบิลด์แนะนำ 3 ช่วงเวลา: ต้นเกม (Early), กลางเกม (Core Build), ท้ายเกม (Late Game) และไอเทมสถานการณ์
   - จุดแข็ง, จุดอ่อน, ฮีโร่ที่ได้เปรียบ (Strong Against) และฮีโร่ที่เสียเปรียบ (Weak Against)
4. **สารานุกรมไอเทม (Items Database):**
   - คลังไอเทมครบ 3 สายหลัก: Weapon (ส้ม), Vitality (เขียว), Spirit (ม่วง)
   - คัดกรองตามระดับ Tier 1 (500), Tier 2 (1,250), Tier 3 (3,000), Tier 4 (6,200+ Souls)
   - แสดงสเตตัส, สกิลติดตัว (Passive), สกิลกดใช้ (Active) และ Win Rate เฉลี่ยเมื่อออกไอเทม
5. **สถิติการกระจายตัวของระดับแรงค์ (Rank Distribution):**
   - กราฟแท่งจำลองสัดส่วนผู้เล่นจริงในทั้ง 11 ระดับแรงค์ (Initiate ถึง Eternus)
   - คำแนะนำและแท็กติกการไต่แรงค์ในแต่ละช่วง (Early Ranks, Mid Ranks, High Ranks)
6. **บทวิเคราะห์แพตช์โน้ต (Patch Notes & Meta Analysis):**
   - สรุปการปรับสมดุลล่าสุดรายฮีโร่ (Buffs & Nerfs) และไอเทม
   - 5 ข้อสรุปสำคัญในการไต่แรงค์ประจำแพตช์

## วิธีการรันโปรเจกต์ (Getting Started)

โปรเจกต์นี้ได้รับการออกแบบให้ทำงานได้ทันทีโดยไม่ต้องผ่านกระบวนการ `npm install` ที่อาจติดปัญหาการซิงค์ของ Google Drive:

```bash
# 1. เข้าสู่โฟลเดอร์โปรเจกต์
cd "g:/My Drive/Obsidian_Vault/1_Projects/deadlock-meta-th"

# 2. เริ่มต้นรันเซิร์ฟเวอร์
node server.js
# หรือ
npm start
```

เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`
